# fab-app: Drug-Disease Link Predictor

**fab-app** is an interactive web interface designed for drug repurposing research. 

By analyzing the bipartite drug-disease network through a **nested Degree-Corrected Stochastic Block Model (nDCSBM)** evaluated over 300 MCMC steps, the application allows users to explore predicted novel candidate interactions for both drugs and diseases based purely on latent network topology.
